Este proyecto compara dos formas de guardar estudiantes usando una tabla hash:

Una tabla hash hecha manualmente en C++.
Un HashMap ya hecho en Java.

Los datos se cargan desde un archivo llamado estudiantes.csv.

Objetivo

Leer los datos de estudiantes desde un archivo CSV y guardarlos en una estructura hash para poder:

Agregar estudiantes.
Mostrar estudiantes.
Buscar un estudiante por su ID.
Eliminar estudiantes.
Ver estadísticas de la tabla.
Archivos usados
main.cpp: programa en C++.
Main.java: programa principal en Java.
Estudiante.java: clase del estudiante en Java.
estudiantes.csv: archivo con los datos de los estudiantes.
EVIDENCIA.pdf: capturas de pantalla o pruebas de que el programa funciona.
